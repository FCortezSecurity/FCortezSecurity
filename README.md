## 📌 A few projects I'd point you to first

### [meridian-pay-baseline](https://github.com/FCortezSecurity/meridian-pay-baseline)
Designed, implemented, and validated AWS security guardrails for a
fictional payments company — closing a real privilege-escalation path and
confirming the fix against a live AWS account, not just on paper. This is
the project that best represents where I'm trying to grow: from finding
attacks to designing environments that resist them.

### [openhound-aws](https://github.com/FCortezSecurity/openhound-aws)
AWS IAM attack-path discovery tool — maps identities, roles, and trust
relationships to surface privilege-escalation chains, in the spirit of
BloodHound's OpenGraph framework.

### [detection-engineering-cicd](https://github.com/FCortezSecurity/detection-engineering-cicd)
An automated pipeline that simulates real MITRE ATT&CK techniques and
validates custom Wazuh detection rules against them, CI/CD-style.
